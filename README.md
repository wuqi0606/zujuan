# 组卷网/学科网试卷打印助手

一个**组卷网（学科网）试卷打印增强油猴脚本**，提供所见即所得的试卷排版预览，帮助你免费下载组卷和试卷、导出高质量 PDF，并完美支持数学公式渲染。

- 适用站点：`zujuan.xkw.com`（组卷网 / 学科网）
- 脚本版本：`6.0.0`
- 许可证：[GNU AGPL v3.0](https://www.gnu.org/licenses/agpl-3.0.html)

---

## 核心功能

- **所见即所得预览** — 单页 / 双页并排预览，自动适应宽度，可手动放大缩小。
- **版式预设** — 内置「紧凑省纸」（默认）与「考试标准」两套版式，一键切换；「恢复默认」回到紧凑省纸。
- **偏好自动记忆** — 字体、字号、行距、页边距、版式等设置通过 `GM_setValue` 自动保存，下次使用直接沿用。
- **公式随字号缩放** — 冻结首渲时公式的基准尺寸，切换字体 / 字号或显示答案时公式按比例缩放，不漂移、不变形。
- **顶层题目工具条** — 在预览中点击任意题目即可选中，顶部工具条出现该题的排版操作：增减答题留白行数、在本题前 / 后强制分页、一键清除，再次点击题目可取消选中。
- **题内自然分页** — 单道题目不会被拆分到两页；章节标题（如「六、三角形」）会与紧随其后的第一道题保持在同一页。
- **打印内容可选** — 试题 / 知识点 / 答案自由组合，支持「答案附末尾」。
- **章节标题双场景兼容** — 同时支持试卷详情页（`.sec-title`）与组卷中心（`.questypetitle`）两种标题结构。
- **去广告** — 自动移除页面浮层广告与 AI 入口等干扰元素。
- **自检模式** — 打开页面时自动校验关键 DOM 与配置依赖（控制台输出），便于排查环境异常；可在编辑器面板开启，或通过 `#selfcheck` 触发。

## 安装

### 第一步：安装油猴管理器

选择你的浏览器安装对应的扩展：

- **Chrome / Edge / Brave** → [Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobp55f)
- **Firefox** → [Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
- **Safari** → [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)

### 第二步：安装本脚本

方式一（推荐）：

1. 下载本仓库的 [`user.js`](./user.js)；
2. 直接把文件拖入 Tampermonkey 管理器的「实用工具 → 导入」区域，或将其作为新脚本打开后保存。

方式二：

1. 在 Tampermonkey 管理器中「新建脚本」；
2. 将本仓库 `user.js` 的全部内容粘贴进去；
3. 保存（`Ctrl/Cmd + S`）。

### 第三步：验证

- 打开 `https://zujuan.xkw.com` 上的任意试卷；
- 页面出现打印入口后点击，即可打开排版预览。

## 使用说明

1. 在组卷网 / 学科网上打开一份试卷；
2. 点击「打印试卷」打开预览窗口；
3. 在顶部工具条选择：
   - 版式预设（紧凑省纸 / 考试标准）；
   - 打印内容（试题 / 知识点 / 答案 / 答案附末尾）；
   - 字体、字号、行距、页边距等；
4. 预览满意后点击「打印」，用浏览器打印功能导出 PDF 或直接打印。

> 脚本会自动保存你的偏好设置，下次打开直接沿用。

## 常见问题

**Q：为什么部分题目答案显示不出来？**
A：答案需在源站手动点击展开（出于网站每日显示次数限制，脚本不会自动触发）。展开后再执行打印即可。

**Q：公式位置错位 / 大小不对？**
A：脚本会在首渲时冻结公式基准尺寸并随字号缩放；如遇异常，可在编辑器面板「恢复默认」重置版式，或刷新页面重新生成预览。

**Q：章节标题跑到了页尾、题目跑到下一页？**
A：预览已对章节标题做 keep-with-next 保护，标题会与紧随的第一道题同页。若仍出现，多为该题目本身超出整页，属正常分页。
